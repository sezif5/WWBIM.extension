# WW.BIM Update Script

## Описание
Скрипт автоматического обновления PyRevit extension WW.BIM из GitHub репозитория без использования version.txt.

## Репозиторий
- **GitHub:** https://github.com/sezif5/WWBIM.extension
- **Ветка:** main (с автоматическим fallback на master)

## Файлы
- `script.py` — основной скрипт обновления для PyRevit

## Как работает
1. Получает SHA и дату последнего коммита через GitHub API
2. Сравнивает SHA с локальным `.wwbim-update-state.json` (старый `last_update.txt` поддерживается как fallback)
3. Если на сервере новее — скачивает ZIP архив репозитория во временную папку
4. Проверяет пути в ZIP и не допускает выход за пределы временного каталога
5. Формирует manifest файлов текущей версии
6. Удаляет только устаревшие файлы из предыдущего manifest
7. Копирует актуальные файлы в папку extension, не затрагивая пользовательские настройки
8. Показывает все ошибки копирования вместо их скрытия
9. Сохраняет SHA, дату, сообщение коммита и manifest
10. Очищает временные файлы

## Установка в PyRevit Extension

### Структура папок
```
WW.BIM.extension/
└── WW.BIM.tab/
    └── Настройки.panel/
        └── Обновить.pushbutton/
            ├── script.py          ← скрипт обновления
            └── icon.png           ← иконка 32x32 (опционально)
```

**Примечание:** `.wwbim-update-state.json`, `.wwbim-manifest.json` и `last_update.txt` создаются автоматически при обновлении.

### Настройки в скрипте
```python
GITHUB_USER = "sezif5"
GITHUB_REPO = "WWBIM.extension"
BRANCHES = ("main", "master")
EXTENSION_NAME = "WWBIM.extension"
```

## Требования
- PyRevit установлен
- Доступ к интернету (github.com)
- Python 2.7+ или Python 3.x (совместим с обоими)

## GitHub API
Скрипт использует GitHub API для получения даты последнего коммита:
- **Endpoint:** `GET /repos/{owner}/{repo}/commits/{branch}`
- **Rate limiting:** 60 запросов/час для неавторизованных запросов
- Достаточно для одного обновления

## Файлы которые НЕ перезаписываются
- `user_config.json`
- `local_settings.py`
- `.user`
- `.wwbim-update-state.json`
- `.wwbim-manifest.json`
- `last_update.txt`
- Любые файлы начинающиеся с `.git`

## Ограничения
- Резервная копия не создаётся по умолчанию.
- Файлы заменяются в текущем процессе Revit; если Windows не позволяет заменить отдельную DLL, ошибка показывается пользователю.
- Для применения новых DLL может потребоваться перезапуск Revit.
- Автоматическая проверка при запуске Revit не выполняется: обновление запускается кнопкой.

## Troubleshooting

### "Не удалось подключиться к серверу"
- Проверьте интернет-соединение
- Проверьте доступ к github.com (корпоративный firewall?)
- Проверьте правильность GITHUB_USER и GITHUB_REPO
- Проверьте что GitHub API доступен (rate limit 60/час для неавторизованных)

### "Не удалось определить путь к плагину"
- Скрипт должен находиться внутри папки .extension
- Или выберите папку вручную в диалоговом окне

### Обновление не применяется
- Перезапустите Revit после обновления
- Проверьте права на запись в папку extension
